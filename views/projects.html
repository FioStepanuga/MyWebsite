FishDex

FishDex is a full-stack app that helps the user identify the fish they catch using AI photo recognition. The app also features catching logs, a region map, security measures, accounts, a pokedex style catch list, and a database of 100 picked out fish in the US. I used C#, TypeScript, PostgreSQL, AWS virtual machine (EC2), Expo, and other software tools.
